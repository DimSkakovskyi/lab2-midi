# Лабораторна робота №2

## Розробка мультимедійного застосунку

**Варіант 2 — соніфікація даних**

## Постановка задачі

Необхідно розробити програму, яка приймає щонайменше два числові показники,
перетворює їх на параметри MIDI та автоматично створює MIDI-файл. Кожен
показник повинен впливати хоча б на один параметр MIDI. Програма також повинна
пояснювати правила перетворення даних і забезпечувати прослуховування
отриманого результату.

У цій реалізації для кожної ноти використовуються чотири вхідні параметри:

| Параметр     | Допустимі значення | Призначення                                |
| ------------ | -----------------: | ------------------------------------------ |
| `Pitch`      |           `0..127` | Визначає висоту MIDI-ноти                  |
| `Velocity`   |           `1..127` | Визначає силу та динаміку звучання         |
| `Duration`   |     `> 0` і `≤ 16` | Визначає тривалість ноти у чвертних долях  |
| `Instrument` |           `1..128` | Визначає інструмент стандарту General MIDI |

Кожен рядок таблиці описує одну ноту. Сукупність рядків утворює послідовну
одноголосну MIDI-композицію.

## Реалізовані можливості

- введення довільної кількості нот у таблиці;
- редагування висоти, velocity, тривалості та інструмента кожної ноти;
- вибір одного зі 128 інструментів General MIDI;
- налаштування темпу композиції в межах `30..300 BPM`;
- автоматична перевірка введених значень;
- відображення зрозумілих повідомлень про помилки;
- перетворення числових параметрів у MIDI-події;
- формування та збереження файлу з розширенням `.mid`;
- прослуховування створеної композиції через системний MIDI-пристрій;
- зупинка відтворення;
- журнал із детальним поясненням перетворення кожної ноти;
- завантаження готового демонстраційного прикладу.

## Правила перетворення даних

### Висота ноти

Значення `Pitch` безпосередньо використовується як номер MIDI-ноти в діапазоні
`0..127`. Для журналу номер додатково перетворюється на музичну назву.

Приклади:

```text
60 → C4
64 → E4
67 → G4
69 → A4
72 → C5
```

### Velocity

Значення `Velocity` передається події `Note On` і визначає силу звучання ноти.
У програмі використовуються такі текстові пояснення:

```text
1..40    → тихо
41..80   → середньо
81..110  → голосно
111..127 → дуже голосно
```

Значення `0` не використовується для звичайної ноти, оскільки в MIDI воно може
інтерпретуватися як завершення звучання ноти.

### Тривалість

Користувач вводить тривалість у чвертних долях. Для MIDI вона переводиться в
ticks. У програмі використовується роздільна здатність `480 ticks` на одну
чверть:

```text
durationTicks = Duration × 480
```

Приклади:

```text
0.25 долі → 120 ticks
0.5 долі  → 240 ticks
1.0 доля  → 480 ticks
2.0 долі  → 960 ticks
```

### MIDI-інструмент

В інтерфейсі інструменти мають зрозумілу користувачу нумерацію `1..128`, а
подія MIDI `Program Change` використовує значення `0..127`. Тому застосовується
формула:

```text
programNumber = Instrument - 1
```

Приклади:

```text
1  — Acoustic Grand Piano → Program Change 0
25 — Acoustic Guitar      → Program Change 24
41 — Violin               → Program Change 40
74 — Flute                → Program Change 73
```

## Алгоритм роботи програми

1. Користувач додає до таблиці одну або декілька нот.
2. Для кожної ноти вводяться `Pitch`, `Velocity`, `Duration` та `Instrument`.
3. Користувач задає темп композиції.
4. Програма зчитує значення з таблиці та перевіряє їхні типи й діапазони.
5. Тривалість переводиться у ticks, а номер інструмента — у номер MIDI Program.
6. Для кожної ноти створюються події `Program Change`, `Note On` і `Note Off`.
7. Події послідовно додаються до одного MIDI-треку.
8. Створений трек записується у файл формату Standard MIDI File.
9. У вікні програми відображається журнал виконаних перетворень.
10. Користувач може прослухати композицію або відкрити файл в іншому
    MIDI-програвачі.


Призначення основних компонентів:

- `MainForm` — інтерфейс користувача та обробка натискань кнопок;
- `MidiNoteInput` — модель однієї введеної ноти;
- `CompositionSettings` — темп і MIDI-роздільна здатність композиції;
- `MidiInputValidator` — перевірка вхідних значень;
- `MidiGenerator` — створення MIDI-подій і запис `.mid`-файлу;
- `MidiPlaybackService` — запуск і зупинка відтворення;
- `MidiNoteHelper` — перетворення номера ноти на її назву та обчислення ticks;
- `GeneralMidiInstruments` — каталог 128 інструментів General MIDI.

## Компіляція та запуск

Відкрити термінал у каталозі, де розміщено `DataSonificationLab.csproj`, і
виконати:

```powershell
dotnet restore
dotnet build
dotnet run
```

Також можна відкрити `DataSonificationLab.sln` у Visual Studio або VS Code та
запустити проєкт клавішею `F5`.

## Контрольний приклад

Для перевірки можна використати такі дані:

|   № | Pitch | Velocity | Duration | Instrument |
| --: | ----: | -------: | -------: | ---------: |
|   1 |    60 |       40 |      1.0 |          1 |
|   2 |    64 |       75 |      0.5 |         25 |
|   3 |    67 |      105 |      2.0 |         41 |
|   4 |    72 |      127 |     0.25 |         74 |

Для `480 ticks` на чверть очікуються такі результати:

```text
1. 60 → C4;  velocity 40;  1.0 → 480 ticks; Instrument 1  → Program 0
2. 64 → E4;  velocity 75;  0.5 → 240 ticks; Instrument 25 → Program 24
3. 67 → G4;  velocity 105; 2.0 → 960 ticks; Instrument 41 → Program 40
4. 72 → C5;  velocity 127; 0.25 → 120 ticks; Instrument 74 → Program 73
```

Під час відтворення повинні змінюватися висота, гучність, тривалість і тембр
нот. Створений файл повинен мати розширення `.mid` і відкриватися у зовнішньому
MIDI-програвачі.

## Перевірка коректності

Для перевірки валідації були передбачені такі випадки:

| Перевірка              | Некоректне значення | Очікувана реакція                         |
| ---------------------- | ------------------: | ----------------------------------------- |
| Порожня композиція     |        немає рядків | Повідомлення про необхідність додати ноту |
| Висота нижче діапазону |                `-1` | Помилка діапазону Pitch                   |
| Висота вище діапазону  |               `128` | Помилка діапазону Pitch                   |
| Нульова velocity       |                 `0` | Помилка діапазону Velocity                |
| Завелика velocity      |               `128` | Помилка діапазону Velocity                |
| Нульова тривалість     |                 `0` | Помилка тривалості                        |
| Текст замість числа    |               `abc` | Повідомлення про некоректне значення      |
| Не вибраний інструмент |    порожня клітинка | Повідомлення про необхідність вибору      |

За наявності помилок MIDI-файл не створюється, програма показує список проблем
і продовжує працювати після їх виправлення.

Правильний Standard MIDI File починається сигнатурою `MThd`, представленою
байтами `4D 54 68 64`.
